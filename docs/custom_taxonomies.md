# Custom Taxonomies

Linneaus classifies Autonomous Systems against a *taxonomy*: a JSON file
mapping category names to descriptions. Three taxonomies ship with the
package (`linneaus`, `asdb`, `isic`), and you can supply your own.

## File format

A taxonomy is a single JSON object. Each key is a top-level category name;
each value is either:

- a **string** — the category description, or
- an **object** — a map of subcategory name → description (the top-level
  category is then described by its subcategories in the prompt).

```json
{
  "Streaming": "Companies whose primary business is audio/video streaming.",
  "Gaming": {
    "Studios": "Game development studios operating their own networks.",
    "Platforms": "Online gaming and matchmaking platforms."
  },
  "Other": "Everything that does not fit the categories above."
}
```

## How names become tags and columns

Category names are *sanitized* — spaces and `/` are replaced with `_` — and
the sanitized names are used as:

1. the values of the LLM structured-output schema (what the model can emit), and
2. the column names of the binary output matrix.

So `"Energy & Utility"` becomes the tag/column `Energy_&_Utility`, and
`"Streaming"` stays `Streaming`. The output CSV has one row per ASN:

```
asn,Streaming,Gaming,Other
15169,0,0,1
```

Descriptions matter: they are inserted verbatim into the system prompt
(see `src/linneaus/resources/prompts.yaml` for the template), and are the
main lever for classification quality. Write them the way you would explain
the category to a colleague, and include an "Other"-style catch-all if you
want every ASN to receive at least one tag.

## Running a custom taxonomy

```bash
# Standalone script (recommended for batch classification)
python scripts/classify.py -i asns.csv -o results.csv --taxonomy my_taxonomy.json

# CLI (LLM-only approach; other approaches use models trained on the
# linneaus taxonomy and do not accept custom taxonomies)
linneaus model predict --approach llm-only --taxonomy-file my_taxonomy.json \
    --input asns.csv --output results.csv --format csv

# With a custom model and/or OpenAI-compatible provider
linneaus model predict --approach llm-only --taxonomy-file my_taxonomy.json \
    --model llama3 --base-url http://localhost:11434/v1 \
    --input asns.csv --output results.csv --format csv
```

Input CSV needs an `asn` column; optional `name` (or `organization_name`),
`website`, and `country` columns improve accuracy considerably.

## Evaluating against your own labels

Create a ground-truth CSV with the same shape as the output (an `asn` column
plus one binary column per sanitized category name), then:

```bash
linneaus model evaluate --taxonomy-file my_taxonomy.json \
    --predictions results.csv --labels my_labels.csv
```

Rows are aligned on `asn`; metrics are computed over the taxonomy's category
columns present in both files.

## Fine-tuning on a taxonomy or category subset

`linneaus model fine-tune` builds its training JSONL from the released labels,
so it supports the builtin taxonomies (whose label matrices exist under
`data/released/202506/labels/`) and category subsets:

```bash
# Fine-tune on a 4-category subset of the linneaus taxonomy
linneaus model fine-tune --tags "Government,Access,Enterprise,ContentProvider"

# Fine-tune on the ASdb taxonomy
linneaus model fine-tune --taxonomy asdb
```

For a fully custom taxonomy you must provide labels in the matching format
and pass them via `--data-dir` using the released directory layout
(`labels/<taxonomy>.parquet` + `splits/assignments.parquet`).

## Builtin taxonomy locations

| Name | Definitions | Labels |
|------|-------------|--------|
| `linneaus` | `src/linneaus/resources/taxonomies/linneaus.json` | `data/released/202506/labels/toplevel.csv` |
| `asdb` | `src/linneaus/resources/taxonomies/asdb.json` | `data/released/202506/labels/asdb.csv` |
| `isic` | `src/linneaus/resources/taxonomies/isic.json` | `data/released/202506/labels/isic.csv` |

The copies under `data/released/202506/*_definitions.json` are published
snapshots generated by `scripts/release_benchmark_labels.py` — edit the
packaged files, then re-run that script to refresh the release.
